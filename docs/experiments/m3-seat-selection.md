# M3 席位选型报告（T-20260919-d2b40240）

基线：qwen3:0.6b 508 tok/s、TTFT 2.6s、VRAM 4.4G、ctx 40k；qwen3.6 36B 60 tok/s、94% CPU offload、VRAM 装不下；worker 领取 +3s。

延迟模型：单席 = TTFT + 256÷速率 + 3s。0.6b ≈ 6.1s/席；36B 生成 4.3s + 3s，重 offload 下 TTFT 估 6–10s，单席 ≈ 13–17s（取 15s）。

**方案A 全 0.6b×3**：端到端 ≈18s；质量低（0.6b 推理弱、三席互评噪声大）；资源风险最小，4.4G 常驻、40k 余量充足。

**方案B 0.6b×2 + 36B 裁判**：≈27s；质量最高，裁判定稿显著拉高上限；风险高：36B 走内存/CPU，占用大且抢占 worker，须分批加载防 OOM 与换页。

**方案C 0.6b×3 常驻 + 36B 仅分歧仲裁**：常态 18s、触发时 ≈34s；质量中高（平时近 A、分歧近 B）；风险中：冷启动延迟尖刺，触发规则不当会退化为 B。

**推荐方案B**：27s 对串行三席可接受；36B 只承担 1/3 时延却决定质量上限；0.6b 双席保吞吐；将 0.6b 锁 VRAM 常驻、36B 用毕即卸即可控险。

**8B/14B 补拉（M3 前）**：qwen3:8b Q4_K_M（≈5.6G，试装 VRAM 替 0.6b 做执行席）；qwen3:14b Q4_K_M（≈9.5G）+ IQ4_XS 兜底（部分 offload 做轻裁判）。拉取后先实测 tok/s 与 TTFT 再定席位，不凭标称。
