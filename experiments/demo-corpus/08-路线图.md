# 智能问答系统设计：产品路线图

## 1. 里程碑回顾

- **M0-M2**：用户/会话/多模型接入骨架，单轮对话可用。
- **M3-M5**：流式输出、协作编排（CONSENSUS/DEBATE）、模型配额。
- **M6-M8**：知识库上传管线、租约队列、引用溯源第一版。
- **M9**：分块策略注册表 + 混合检索 + 60 QA 评测体系，检索质量成为一等公民。
- **M10**：答辩冲刺——引用悬浮、headingPath 过滤、演示数据与脚本。

## 2. M11+ 规划

按优先级排序的候选特性：

1. **重排模型（reranker）**：bge-reranker 接入 RRF 之后、MMR 之前。
2. **查询改写**：多轮对话指代消解，改写后检索。
3. **多模态文档**：图片 OCR 入索引，表格结构化导出。
4. **部署硬化**：HTTPS 反代、生产级密钥轮换、备份恢复演练。

## 3. 技术债清单

| 债项 | 影响 | 计划 |
| --- | --- | --- |
| PDF 解析无 OCR | 扫描件不可索引 | M11 评估 pprl |
| 全文索引 simple 配置 | 英文停用词进入 tsv | 引入自定义词典 |
| 检索无缓存 | 相似问题重复计费 | Redis 语义缓存 |

## 4. 度量驱动的迭代原则

任何检索侧改动必须先跑 60 QA 基线再合入；
命中率回退超过 3 个点的改动默认拒绝，除非伴随明确的场景取舍说明。
