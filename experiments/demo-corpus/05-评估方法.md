# 智能问答系统设计：评估方法学

## 1. 三层评估体系

1. **单元/集成测试**：vitest 覆盖分块器、检索 SQL、租约状态机。
2. **离线检索评测**：固定 60 QA 中文数据集，top-5 命中率为主指标，Wilson 95% 置信区间报告波动。
3. **LLM 判分**：qwen3:8b 作裁判，对生成答案与标准答案做 0/1 判定，判分协议冻结于 protocol-v1。

## 2. 数据集构造

- 60 个问题按难度分层：20 单跳事实题、25 跨节推理题、15 干扰题（语料中无答案，考察拒答）。
- 每题标注出处文档与标准答案摘要，判分时隐藏出处防止裁判偷懒。
- 同一数据集跨策略复用，保证 fixed/recursive/structure 与混合臂可比。

## 3. 关键指标定义

| 指标 | 定义 |
| --- | --- |
| top-5 命中率 | 标准出处块出现在检索前 5 的比例 |
| MRR | 标准出处块排名倒数的均值 |
| 拒答正确率 | 干扰题上未编造答案的比例 |
| 首包延迟 | 请求发出到首个 SSE chunk 的 P50/P95 |

## 4. 实验纪律

- 每次实验产出 JSON 原始结果 + Markdown 汇总表，双文件入库（experiments/results）。
- 改动检索逻辑必须先冻结基线，臂间只允许单一变量差异。
- 判分模型与温度固定，禁止为提分调裁判。

## 5. 已知局限

- 60 QA 规模下 ±1 题约等于 1.7 个百分点，小于 5 个点的差异需谨慎解读。
- LLM 判分存在约 3% 的裁判噪声，重要结论以人工复核为准。
