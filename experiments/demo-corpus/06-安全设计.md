# 智能问答系统设计：安全设计

## 1. 认证与会话

- better-auth 邮箱密码登录，密码哈希 scrypt，无第三方社交登录。
- 会话有效期 7 天，1 天滑动续期；Secure Cookie 跟随部署协议自动切换。
- 登录接口与业务 API 全部经服务端会话校验，无匿名读路径。

## 2. 数据隔离

- 所有 KB/Document/Chunk 查询都以 userId 属主校验为第一谓词。
- 检索权限过滤内联在 SQL 中（见《混合检索》篇），杜绝先检索后鉴权。
- 跨用户 parentId 无法泄露他人文档：父块查询带同样的属主条件。

## 3. 上传安全

- 白名单 MIME：仅 text/plain、text/markdown、application/pdf。
- 大小上限 20MB（MAX_FILE_BYTES），文本上限 200 万字符。
- PDF 解析运行在独立 worker 线程，60 秒超时，防止恶意文件阻塞主循环。
- 对象键格式 `userId/kbId/documentId`，桶私有、无预签名 URL。

## 4. 密钥与配置

- 第三方 API Key 以 AES-256-GCM 加密存储，密钥来自 ENCRYPTION_KEY 环境变量。
- .env 永不入库，模板 .env.example 提交；生产密钥必须替换示例值。
- 本地冒烟开关 AICHAT_LOCAL_SMOKE 生产环境禁止设置。

## 5. 依赖与审计

- 依赖锁定 pnpm-lock.yaml，CI 安装走 frozen-lockfile。
- M9 安全审计覆盖注入、越权、密钥泄露三类，未发现高危项。
- 提示注入防线：检索到的原文以引述块包裹，并在系统提示中声明其不可信。
